# 🎬 ClipVault

### Your moments. Saved.

**ClipVault** is a modern, lightweight Windows application designed to organize, manage, and preserve your best gaming moments.

No cloud. No subscriptions. Just your clips, organized your way.

Developed by **Nikita Batalov**.

---

## ✨ Features

### 🎮 Smart Game Organization
Automatically create organized folder structures for popular games:

- Counter-Strike 2
- Dota 2
- Fortnite
- Valorant
- PUBG
- Apex Legends
- Call of Duty: Warzone
- Rainbow Six Siege
- Minecraft

Create custom games, categories, and folder templates.

### 📁 Automatic Clip Sorting
Import your gaming clips and organize them by game and highlight type.

For example:

```
ClipVault/
├── CS2/
│   ├── 1 Frag/
│   ├── 2 Frags/
│   ├── 3 Frags/
│   ├── 4 Frags/
│   ├── Ace/
│   ├── Ninja Defuse/
│   └── Funny Moments/
├── Dota 2/
└── Fortnite/
```

### 🏷️ Custom Tags & Colors
Organize your clips using custom icons, color labels, and categories.

Quickly filter your library to find exactly what you're looking for.

### 👥 Friends Tagging
Tag friends who appear in your clips.

Find shared gaming moments and export selected videos to share with them.

### 🎞️ Video Library
- Video thumbnails
- Built-in video preview
- Search and filtering
- Drag-and-drop importing
- Automatic detection of new clips
- Local file management

### 🎨 Modern Interface
A clean, dark interface with orange accents, designed for gamers and content creators.

---

## 💻 System Requirements

- Windows 10 / 11
- 64-bit operating system
- .NET 8 for development
- Visual Studio 2022 or newer for building from source

The self-contained release build does not require a separate .NET installation.

---

## 🚀 Installation

1. Open the **Releases** section.
2. Download the latest `ClipVault.exe`.
3. Launch the application.
4. Select your library location.
5. Create game folders and start importing clips.

No account required.

## 🔒 Privacy

ClipVault is designed to work locally.

Your videos and library data remain on your computer. No cloud storage or online account is required.

## ⚠️ Beta Notice

ClipVault is currently in beta.

Some features may contain bugs or behave unexpectedly. Back up important clips before using file-moving operations.

Automatic gameplay recognition is not currently supported. Clip categories are assigned manually.
